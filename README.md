# Opus 5.5 MG Animation Collection

A growing collection of motion-graphics animations created with Opus 5.5.

Each work is kept in its own folder. To view a work, open that folder and double-click its `index.html` file. The pages are self-contained browser builds, so no server or package installation is needed for normal viewing.

## Works

### `normal-friend/`

The first collection item: a Canvas MG animation inspired by Tao Zhe's **《普通朋友》**. Open [`normal-friend/index.html`](normal-friend/index.html) to view it. Its modular source files and poster artwork are in the same folder.

## Adding another work

Add a new folder beside `normal-friend/` and include that work's browser entry point as `index.html`. Keep each work self-contained so it can be opened directly from its folder.

The repository intentionally stores source files, generated browser bundles, and presentation artwork. Local audio files and recorded video exports are ignored; each animation can load a legally obtained local audio file through its own player when needed.
